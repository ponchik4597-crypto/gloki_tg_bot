# Gloki Bot 🤖

## Быстрый старт

Проект использует современный менеджер пакетов [uv](https://github.com).

### Установка зависимостей и создание окружения
`uv` автоматически создаст виртуальное окружение `.venv` и установит все пакеты:
```bash
uv sync
```
### Запуск бота
Запустите проект локально через модуль `src.main`:
```bash
uv run python -m src.main
```

## Разработка (Команды Makefile)
В проекте настроен `Makefile` для автоматизации рутинных задач.
*   `make format` — автоматически исправить форматирование кода с помощью Ruff.
*   `make lint` — проверить код на ошибки и соответствие стилю.
*   `make check` — запустить полную проверку (линтер + форматирование).

## Запуск в Docker

**Запуск проекта:**
```bash
docker-compose up --build -d
```

**Остановка проекта:**
```bash
docker-compose down
```

## Структура проекта
*   `src/` — основной исходный код бота.
*   `tests/` — автоматические тесты
*   `pyproject.toml` — конфигурация проекта, его зависимостей и инструментов (Ruff, uv).
*   `Makefile` — ярлыки для частых команд разработчика.
*   `Dockerfile` & `docker-compose.yml` — конфигурация контейнеризации приложения.
