# Gloki Bot 🤖

## Быстрый старт

Проект использует современный менеджер пакетов [uv](https://github.com).

### Установка зависимостей и создание окружения
`uv` автоматически создаст виртуальное окружение `.venv` и установит все пакеты:
```bash
uv sync
```
### Настройка окружения
```bash
cp .env.example .env
```
### База данных (Миграции)
Перед первым запуском примените миграции Alembic для создания таблиц в БД:
```bash
uv run alembic upgrade head
```
### Запуск бота
Запустите проект локально через модуль `src.main`:
```bash
uv run python -m src.main
```

## Разработка (Команды Makefile)
В проекте настроен `Makefile` для автоматизации рутинных задач.
*   `make format` - автоматически исправить форматирование кода с помощью Ruff.
*   `make lint` - проверить код на ошибки и соответствие стилю.
*   `make check` - запустить полную проверку (линтер + форматирование).
*   `uv run ruff check . --fix` - автоисправление

## Запуск в Docker

**Запуск проекта:**
```bash
docker-compose up --build -d
```

**Просмотр логов приложения:**
```bash
docker compose logs -f bot
```

**Остановка проекта:**
```bash
docker-compose down
```

## Структура проекта

* `src/` – основной исходный код бота (содержит main.py, bot.py, папки core/, handlers/, services/).
* `tests/` – автоматические тесты.
* `pyproject.toml` – конфигурация проекта, зависимости и инструменты (Ruff, uv).
* `Makefile` – ярлыки для частых команд разработчика.
* `Dockerfile` и docker-compose.yml – конфигурация контейнеризации приложения.
* `alembic.ini` – настройки миграций базы данных.
* `sqlite.db` – локальная база данных SQLite (для разработки).
* `uv.lock` – lock-файл зависимостей.
